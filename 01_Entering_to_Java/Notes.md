# Компиляция и запуск программы:
- Встроенный компилятор java : ```javac```
- Если в ```javac``` скормить класс с точкой входа в программу, он подтянет нужные ему файлы проекта автоматически - если они в одной и той же директории. 

- Исходник → Компилятор → Байт-код Java → JVM

```bash 
javac GameLauncher.java # компиляция
java GameLauncher.class  # запуск
```

- Gradle

# Структура кода
- Файл исходного кода (с раширением .java) может содержать несколько классов
- Только 1 из классов внутри файла может быть публичным
- Имя публичного класса совпадает с именем файла
- Класс - это часть программы
- Содержимое класса заключается в фигурные скобки
---
- В классе могут быть 1-n методов 
- Метод может: сделать что-то, делать что-то снова и снова, сделать что то при условии.

# Инфо
- ООП позволяет дополнять приложения, не затрагивая работающий код.
- Весь код в Java находится внутри классов.
- Класс описывает, как создавать объект определенного вида.
- Класс - это что-то вроде шаблона.
- Объект может сам о себе позаботиться - нам не нужно знать как именно он это делает.
- Объект знает что-то и умеет что-то делать
- Переменные экземпляра - это состояние объекта.
- Методы объекта - определяют поведение объекта.
-  Для каждого класса можно предусмотреть отдельный тестовый класс, который будет использоваться для создания класса
- Класс может наследовать поля и методы от более абстрактного суперкласса
- Программа на Java - это набор объектов, которые общаются между собой.
