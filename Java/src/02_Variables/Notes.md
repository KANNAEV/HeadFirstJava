## Переменные бывают 2 видов:
- примитивные (простые типы)
- ссылочные (ссылки на объекты)

## Размеры примитивов
<br>boolean =    true/false
<br>char = 16 бит
<br>byte = 8 бит
<br>short = 16 бит
<br>int = 32 бит
<br>long = 64 бит
<br>float = 32 бит
<br>double = 64 бит

<br>Переменные на примитивный тип хранят само значение. 
<br>Переменные на ссылочный тип хранят ссылку на объект а не сам объект.

Для помощи компилятору иногда указывают букву в присваивании
```java
float f = 32.5f;
long l = 34532L;
```

Большую сущность поместить в маленькую не получится (переполнение).
А наоборот - можно 
``` java
short short_var = 2;
int int_var = 100;
short_var = int_var // Ошибка ! short < int
int_var = short_var // Сработает int (называется неявным приведением типов).

```

## Ссылочне переменные
- Переменная ссылка на объект хранит биты, указывающие на путь к объекту.
- С помощью оператора точки [ . ] можно получить метод из объекта переменной.
- Объекты существуют в куче

```java
byte x = 7;  // Биты представляющие число 7 хранятся в переменной примитива
Dog myDog = newDog(); // В ссылочной переменной Dog не хранится сам объект
```

- Три шага на пути появления объекта:
```java 
Dog myDog = new Dog(); 
// 1. Dog myDog Объявление. Выделяется память на ссылочную переменную для хранения типа Dog 
// 2. new Dog() Создание и моединение ссылки объекта. Выделяется память в куче для создания объекта Dog 
// 3. = присваиваем ссылочной переменной новый объект типа Dog
```

- Разные ссылочные переменные могут ссылаться на один и тот же объект.


## Массивы

- Массивы - это объекты, даже если он хранит список примитивов.
- Каждый элемент в массиве это 1 из 8 простых типов переменных или ссылочная переменная (а не сам объект)
```javaцц
int nums[]; // Объявление переменной массива int. (объект Array в JVM)
nums =  new int[3] // Создает новый целочисленный массив и присвоит ранее объявленной переменной массива nums
nums[0] = 1; 
nums[1] = 2;
nums[2] = 3;
```


## Память
- Объекты хранятся в куче. За памятью кучи следит сборщик JVM.
В Java "объект" и  "класс" это синонимы.

- Размер памяти у ссылок одинаковый для всех объектов в пределах одной JVM

- Массивы - это тоже объект даже если он содержит примитивы.

- Арифметика с ссылками как арифметика с указателями в си недоступна.

- Переменная ссылка может указывать на один тип объекта , далее можно на нее переприсвоить на другой объект того же типа (ну если переменная объявлена не как final)

- Garbage Collection (GC) - в сборщик мусора попадают объекты, на которые больше нет ссылок от переменных.

- Чтобы освободит переменную от связи с объектом - достаточно присвоить ей null

``` java
Book c = new Book();
c = null;
```
