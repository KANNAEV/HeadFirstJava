# Классы и объекты

- ООП позволяет дополнять приложение не затрагивая проверенные участки кода
- Программа на Java - это набор классов, 1 из которых содержит  основной метод main()
- Есть спец-программы кроторые могут упаковать программу вместе с нужной версией JVM (установочный файл)
- Так же программу можно упаковать в jar файл - внутри сотни классов Вашей программы и манифест-файл в котором указан 1 основной класс с методом main()

- Класс - это шаблон будущих объектов
- Класс - это не объект, но нужен для создания объектов
- Класс содержит: переменные и методы
- Методы - это действия которые может совершать будущий объект
- Переменные - это то что объект знает о себе, в отличии от методов они могу меняться

## Пример: класс Автомобиль
- [Класс Car](./Car/Car.java)
- Оператор `.` дает доступ к переменным обекта и его методам
- Метод main() может быть для точки входа в целую программу или для теста классов.
- Использования метода main для [теста класса Car](./Car/CarTestDrive.java)

- Объекты попадают в кучу (heap)
- JVM управляет очищает объекты из кучи если на него больше не ссмылаются переменные

- Ключевые слова `public` и `static` помогают сделать методы глобальными
