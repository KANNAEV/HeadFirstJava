# Методы

- Класс - это шаблон объекта. Внутри класса описываются его свойсва и методы
- Все экземпляры одного и того же класса имеют одинаковые методы
- Методы могут вести себя по разному в зависимости от значений переменных экземпляра.

>Пример: [класс Dog](./Dog.java) . В зависимости от веса собаки, метод Song() собаки может Гавкать, Тявкать, или Пикать



## Аргумеyты и параметры
- Метод можно вызвать с передачей ей аргументов
- Тогда метод должен использовать параметры
- Вызываюющий код - передает аргументы, а метод использует параметры.


## Значения из метода можно возвращать
```java
int giveCode() {
    return 42;
}
```

- Методу можно передать сразу несколько значений
- Порядок аргументов соотвествует порядку параметров метода
```java 
// Вызов метода с двумя параметрами и передача ему двух аргументов
void proga () {
  myClock c = new myClock();
  int new_hours = 12;
  int new_minutes = 30;
  c.showTime(new_hours, new_minutes);
}

void showTime (int hours, int minutes) {
    System.out.println(hours +":" minutes);
}

```

- В Java передача осуществляется по значению (копия знаяения из переменной)
- Метод не может изменить содержимое переменной, которую ей передали
- Метод может вернуть только 1 значение
- Если нужно вернуть несколько значений - то можно вернуть массив
- Значения, принимаемые и возвращаемые методом, могут быть неявно приведены к более вместительному виду или явно приведены к менее вместительному.
- Тип метода void означает, что метод ничего не возвращает.

## Геттеры и Сеттеры (accessors and mutators)
- Геттеры и Сеттеры позволяют получать и устанавливать значения
```java
class Car {
    String brand;
    int engineVolume;

    void getBrand () {return brand;}
    void getEngineVolume() {return engineVolume;}

    void setBrand (String newBrand) {brand = newBrand;}
    void setEngineVolume (int newVolume) {engineVolume = newVolume;}

}
```

## Инкапсуляция

- Переменные экземпляра должны быть приватны
- Геттеры и сеттеры должны быть публичны
- Помечай свои переменные экземпляра модификатором `private`, добавляя `public` геттеры и сеттеры
- Защищай сеттеры от некорректных данных
```java
// Объём бензинового двигателя не может быть 0
  void setEngineVolume (int newVolume) {
    if (newVolume > 0) {
        engineVolume = newVolume;
    }
   }
```
