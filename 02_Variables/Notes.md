## Переменные бывают 2 видов:
- примитивные (простые типы)
- ссылочные (ссылки на объекты)

## Размеры примитивов
<br>boolean =    true/false
<br>char = 16 бит
<br>byte = 8 бит
<br>short = 16 бит
<br>int = 32 бит
<br>long = 64 бит
<br>float = 32 бит
<br>double = 64 бит

<br>Переменные на примитивный тип хранят само значение. 
<br>Переменные на ссылочный тип хранят ссылку на объект а не сам объект.

Для помощи компилятору иногда указывают букву в присваивании
```java
float f = 32.5f;
long l = 34532L;
```

Большую сущность поместить в маленькую не получится (переполнение).
А наоборот - можно 
``` java
short short_var = 2;
int int_var = 100;
short_var = int_var // Ошибка ! short < int
int_var = short_var // Сработает int (называется неявным приведением типов).

```

## Память
<p>Объекты хранятся в куче. За памятью кучи следит сборщик JVM. <p>
В Java "объект" и  "класс" это синонимы.

Массивы - это тоже объект даже если он содержит примитивы.


<br> Арифметика с ссылками как арифметика с указателями в си недоступна.

Переменная ссылка может указывать на один тип объекта , далее можно на нее переприсвоить на другой объект того же класса (ну если переменная объявлена не как final)

Garbage Collection (GC) - в сборщик мусора попадают объекты, на которые больше нет ссылок от переменных.

Чтобы освободит переменную от связи с объектом - достаточно присвоить ей null

``` java
Book c = new Book();
c = null;
```
