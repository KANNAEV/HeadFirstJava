# Интерфейсы и абстрактные классы
- или "Серьезный полиморфизм"


- Например, у нас есть класс `Animal` от которого наследуются классы `Cat` и `Dog`
- Но зачем нам нужен объект `Animal` , вдруг его кто-то создаст
- Такой объект не будет нести никакого смысла.
- На этот счет есть способ не дать никому создать объект данного класса - пометив его как `abstract`

- Если класс не `абстрактный` - то он `конкретный`

- Абстрактными могут быть и методы
- Если класс абстрактный - значит его нужно расширить
- Если метод абстрактный - значит его нужно переопределить

- Нельзя иметь абстрактный метод в неабстрактном классе
```java
abstract public void eat(); // У метода нет тела
```
- Но можно совмещать неабстрактные методы в абстрактном классе
